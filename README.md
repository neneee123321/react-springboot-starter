## 📖 강의 소개

### 👋 이 강의는 이런 강의입니다

이 강의는 **프로그래밍 경험이 전혀 없는 비전공자, 입문자**도 처음부터 따라올 수 있도록 기획된 **React + Spring Boot 풀스택 개발 입문 과정**입니다.

웹 개발을 처음 배우면 보통 “프론트엔드”와 “백엔드”가 나뉘어 있어 각각 따로 학습해야 하는 어려움이 있습니다. 하지만 이 강의에서는 **프론트엔드(React)** 와 **백엔드(Spring Boot)** 를 동시에 배우며, 실제로 작동하는 **풀스택 애플리케이션**을 만들어보는 경험을 제공합니다.

### 🙋 이런 분들에게 추천합니다

- 프로그래밍을 처음 시작하는 **비전공자 / 입문자**
- HTML, CSS, JavaScript 정도만 조금 아는 상태에서 **웹 개발을 본격적으로 배우고 싶은 분**
- React와 Spring Boot를 함께 활용해보고 싶은 분
- 단순히 코드만 배우는 것이 아니라, **웹 서비스가 동작하는 전체 흐름**을 이해하고 싶은 분
- “나도 내가 만든 웹 서비스를 직접 배포해보고 싶다!” 하는 분

### 📌 이 강의를 통해 배우는 것

- 웹 페이지가 만들어지는 기본 원리 (클라이언트 & 서버)
- React를 활용한 프론트엔드 개발 기초
- Spring Boot를 활용한 백엔드 개발 기초
- 데이터베이스와 API 연동 방법
- 프론트엔드와 백엔드를 연결하여 **하나의 서비스**로 만드는 방법
- 나만의 미니 프로젝트 제작 & 배포 경험

### 📚 사전 지식은 어느 정도 필요할까요?

- **프로그래밍을 전혀 몰라도 괜찮습니다.**
    
    설치부터 차근차근 알려드립니다.
    
- 컴퓨터 기본 조작(프로그램 설치, 파일 저장, 인터넷 검색 등)만 할 수 있다면 충분합니다.
- 혹시 HTML이나 JavaScript를 조금 알고 있다면, 더 빠르게 이해할 수 있지만 필수는 아닙니다.

### 🌟 강의가 끝나면?

👉 당신은 **“내가 만든 웹 서비스”** 를 직접 보여줄 수 있습니다.

👉 코딩을 처음 시작한 비전공자도, **풀스택 개발자 첫걸음**을 뗄 수 있습니다.
